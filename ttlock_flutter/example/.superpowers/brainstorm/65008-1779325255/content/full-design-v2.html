二、数据模型与持久化（所有设备全量持久化）

核心设计：每种设备独立 freezed 模型 + 独立 Storage 类。 配件通过 boundLockMac 字段关联到所属锁。锁详情页加载时，从本地存储读取该锁绑定的配件列表。
// 锁设备（已有，增强） @freezed class SavedLockDevice with _$SavedLockDevice { const factory SavedLockDevice({ required String name, required String mac, required String lockData, required TTLockVersion lockVersion, required DateTime initializedAt, }) = _SavedLockDevice; factory SavedLockDevice.fromJson(Map<String,dynamic> json) => _$SavedLockDeviceFromJson(json); } // 网关设备（新增） @freezed class SavedGatewayDevice with _$SavedGatewayDevice { const factory SavedGatewayDevice({ required String name, required String mac, required String gatewayModel, required DateTime initializedAt, }) = _SavedGatewayDevice; } // 门磁（新增，绑定到锁） @freezed class SavedDoorSensor with _$SavedDoorSensor { const factory SavedDoorSensor({ required String name, required String mac, required String boundLockMac, // 所属锁 MAC required DateTime initializedAt, }) = _SavedDoorSensor; } // 遥控器（新增，绑定到锁） @freezed class SavedRemoteKey with _$SavedRemoteKey { const factory SavedRemoteKey({ required String name, required String mac, required String boundLockMac, required DateTime initializedAt, }) = _SavedRemoteKey; } // 键盘（新增，绑定到锁） @freezed class SavedKeypad with _$SavedKeypad { const factory SavedKeypad({ required String name, required String mac, required String boundLockMac, required bool isMultiFunction, required DateTime initializedAt, }) = _SavedKeypad; } // 水电表（新增，独立设备） @freezed class SavedMeterDevice with _$SavedMeterDevice { const factory SavedMeterDevice({ required String name, required String mac, required String meterId, required String meterType, // 'water' | 'electric' required DateTime initializedAt, }) = _SavedMeterDevice; }

存储方式：每种设备类型独立 SharedPreferences key + JSON 序列化

三、通用扫描页 ScanPage

class ScanConfig { final ScanMode mode; // main / accessory final DeviceType? deviceType; // 预选设备类型 final String? lockData; // 配件模式：所属锁的 lockData final String? lockMac; // 配件模式：所属锁的 MAC }
🔵 主扫描模式
1. 显示类型选择器（锁/网关/水表/电表）
2. 用户选类型 → 扫描 BLE
3. 设备列表（名称/MAC/信号）
4. 点击 → SDK init → 持久化 → 跳转详情页
🟡 配件扫描模式
1. 不显示类型选择器，直接扫描指定类型
2. SDK init 时传入 lockData
3. 持久化配件数据（含 boundLockMac）
4. 跳转配件详情页

四、锁详情页（3 个 Section）

Section 1：控制命令
  • 开关锁大按钮
  • 密码管理：增/删/改/查
  • 卡片/指纹/人脸管理
  • 操作记录
  • 需参数命令 → 弹出配置对话框
Section 2：绑定配件
  • 从本地存储读取 lockMac 匹配的配件
  • 🔗 门磁 — 状态卡片 +「添加」按钮
  • 🔗 遥控器 — 列表 +「添加」按钮
  • 🔗 键盘 — 状态卡片 +「添加」按钮
  • 点击「添加」→ ScanPage(配件模式, lockMac)
  • 点击已绑定配件 → 配件详情页
  • 配件管理（重命名/删除/解绑）
Section 3：锁配置
  • 音量 / 方向 / 自动锁定
  • 通行模式 / 双认证
  • WiFi 配网 / 服务器配置
  • 电梯控制 / NB-IoT
  • 重置锁 / 重置 Ekey

命令参数配置对话框示例

• 创建密码：弹窗 → 密码输入 + 起止日期选择 → 执行
• 设置自动锁定：弹窗 → 滑动条选秒数 → 执行
• 配置 WiFi：弹窗 → SSID + 密码输入 → 执行
• 修改有效期：弹窗 → 日期选择器 → 执行

五、锁数据加载流程

打开锁详情 /lock/:mac: 1. 从 SavedLockDevice 列表加载锁信息（name, lockData） 2. 从 SavedDoorSensor 列表过滤 boundLockMac == mac → 门磁列表 3. 从 SavedRemoteKey 列表过滤 boundLockMac == mac → 遥控器列表 4. 从 SavedKeypad 列表过滤 boundLockMac == mac → 键盘列表 5. 显示在 Section 2 配件区域
