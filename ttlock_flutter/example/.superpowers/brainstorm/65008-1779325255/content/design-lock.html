页面布局（3 个 Section）

Section 1：控制命令
• 开关锁（大按钮）
• 命令列表分组：
🔐 密码管理（增/删/改/查）
💳 卡片管理（查/清）
👆 指纹管理（查/清）
👤 人脸管理（查/清）
📋 操作记录
改进：需要参数的命令点击后弹出参数配置对话框
Section 2：绑定配件
• 🔗 门磁 — 状态卡片（已绑定/未绑定）
已绑定：显示电量、报警设置 → 点击进入详情
未绑定：「添加门磁」按钮 → 跳转 ScanPage(accessory)
• 🔗 遥控器 — 列表 + 添加按钮
• 🔗 键盘 — 状态卡片 + 添加按钮
Section 3：锁配置
• 🔊 音量设置（选择器）
• ↔️ 开门方向（左/右）
• ⏱ 自动锁定时间
• 🚪 通行模式
• 📶 WiFi 配网
• 🔄 重置锁
• 🛗 电梯控制

命令参数配置对话框

对于需要参数的命令，不再硬编码值，改为弹窗输入：

示例：「创建自定义密码」
→ 弹出 BottomSheet/Dialog
→ 密码输入框（TextFormField）
→ 生效起始时间（日期选择器）
→ 生效结束时间（日期选择器）
→ 【确认执行】按钮 → 调用 API → 显示结果

示例：「设置自动锁定时间」
→ 弹出 BottomSheet
→ 滑动条或数字输入
→ 【确认】→ API 调用 → 结果

示例：「配置 WiFi」
→ SSID 输入框 + 密码输入框
→ 【确认】→ API 调用

配件详情页（从锁详情进入）

门磁详情页：设备名称、MAC、电量、门未关报警开关、删除门磁
遥控器详情页：设备名称、MAC、电量、有效期设置、删除遥控器
键盘详情页：设备名称、MAC、电量、添加指纹/卡片入口、删除键盘
