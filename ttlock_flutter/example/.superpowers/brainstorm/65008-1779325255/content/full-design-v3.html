三、锁详情页（3 个 Section）

Section 1：控制命令
  • 开关锁大按钮
  • 密码/卡片/指纹/人脸管理
  • 操作记录
  • 命令需参数 → 弹窗配置
Section 2：配件入口（箭头导航）
  • 🔗 门磁 — 点击 → 门磁列表页
  • 🔗 遥控器 — 点击 → 遥控器列表页
  • 🔗 键盘 — 点击 → 键盘列表页
  • 各入口可显示已绑定数量
Section 3：锁配置
  • 音量/方向/自动锁定
  • 通行模式/双认证
  • WiFi 配网/服务器
  • 电梯/NB-IoT
  • 重置

四、数据模型 — 所有设备全量持久化

// 锁 @freezed class SavedLockDevice { name, mac, lockData, lockVersion, initializedAt } // 网关 @freezed class SavedGatewayDevice { name, mac, gatewayModel, initializedAt } // 门磁（boundLockMac 关联锁） @freezed class SavedDoorSensor { name, mac, boundLockMac, initializedAt } // 遥控器（boundLockMac 关联锁） @freezed class SavedRemoteKey { name, mac, boundLockMac, initializedAt } // 键盘（boundLockMac 关联锁） @freezed class SavedKeypad { name, mac, boundLockMac, isMultiFunction, initializedAt } // 水电表 @freezed class SavedMeterDevice { name, mac, meterId, meterType, initializedAt }

存储：SharedPreferences + JSON，每类独立 key

五、通用扫描页 ScanPage

主扫描模式（从底部 Tab 进入）
1. 显示类型选择器（锁/网关/水表/电表）
2. 选类型 → BLE 扫描 → 设备列表
3. 点击 → 初始化 → 持久化 → 跳转详情
配件扫描模式（从配件列表页 "+" 进入）
1. 不显示选择器，直接扫描指定类型
2. 扫描结果列表
3. 点击 → SDK init（传入 lockData）
4. 持久化（含 boundLockMac）→ pop 回列表页（刷新）
