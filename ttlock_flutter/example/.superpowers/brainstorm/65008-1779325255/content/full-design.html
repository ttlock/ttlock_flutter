方案 A：保留现有 Provider 模式 + 通用扫描页

一、导航架构

📊 Dashboard
TabBar（锁/网关/水表/电表）
🔍 扫描
参数化，支持主扫描 + 配件扫描

• /remote-key/:mac — 遥控器详情页

• /water-meter/:id — 水表详情页
• /electric-meter/:id — 电表详情页

二、数据模型与持久化

// 锁 — 持久化（继承现有 SavedDevice） @freezed class SavedLockDevice with _$SavedLockDevice { const factory SavedLockDevice({ required String name, required String mac, required String lockData, required TTLockVersion lockVersion, required DateTime initializedAt, }) = _SavedLockDevice; factory SavedLockDevice.fromJson(Map<String,dynamic> json) => _$SavedLockDeviceFromJson(json); } // 网关 — 持久化（新增） @freezed class SavedGatewayDevice with _$SavedGatewayDevice { const factory SavedGatewayDevice({ required String name, required String mac, required String gatewayModel, required DateTime initializedAt, }) = _SavedGatewayDevice; } // 水表/电表 — 持久化（新增） @freezed class SavedMeterDevice with _$SavedMeterDevice { const factory SavedMeterDevice({ required String name, required String mac, required String meterId, required String meterType, // 'water' | 'electric' required DateTime initializedAt, }) = _SavedMeterDevice; }

配件不持久化：门磁/遥控器/键盘绑定在锁上，每次打开锁详情时通过 SDK 实时查询
存储方式：SharedPreferences + JSON 序列化，每类设备独立 Storage 类

三、通用扫描页 ScanPage

// 扫描配置 class ScanConfig { final ScanMode mode; // main / accessory final DeviceType? deviceType; // 预选设备类型 final String? lockData; // 配件模式：所属锁的 lockData final String? lockMac; // 配件模式：所属锁的 MAC } enum ScanMode { main, accessory }
主扫描模式
1. 显示类型选择器（锁/网关/水表/电表）
2. 用户选类型 → 扫描 BLE
3. 设备列表（名称/MAC/信号）
4. 点击 → 初始化 → 持久化 → 跳转详情
配件扫描模式
1. 不显示类型选择器
2. 直接扫描指定类型（门磁/遥控/键盘）
3. 点击设备 → SDK init（传入 lockData）
4. 成功 → 跳转配件详情页

四、锁详情页（3 个 Section）

Section 1：控制命令
  • 开关锁大按钮
  • 密码管理：增/删/改/查
  • 卡片管理：查/清
  • 指纹管理：查/清
  • 人脸管理：清
  • 操作记录
  • 需参数命令 → 弹出配置对话框
Section 2：绑定配件
  • 🔗 门磁（已绑定/未绑定 + 添加按钮）
  • 🔗 遥控器（列表 + 添加按钮）
  • 🔗 键盘（状态 + 添加按钮）
  • 点击「添加」→ 跳转 ScanPage(配件模式)
  • 已绑定配件 → 点击进入详情页
Section 3：锁配置
  • 音量 / 方向 / 自动锁定
  • 通行模式 / 双认证
  • WiFi 配网
  • 电梯控制
  • 重置锁 / 重置 Ekey

命令参数配置对话框

• 创建密码 → 弹窗输入密码 + 起止时间
• 设置自动锁定 → 滑动条选择秒数
• 配置 WiFi → SSID + 密码输入框
• 配置服务器 → IP + Port 输入框
• 修改有效期 → 日期选择器
